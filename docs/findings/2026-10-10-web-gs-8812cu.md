# Web GS on the RTL8812CU (2026-10-10)

**Status:** the RTL8812CU (0bda:c812, Jaguar3 8822C) is a supported web GS card; current behaviour, the driver-disk eject and the `rtw88_8822cu` caveat → `docs/web-gs.md`.

Extracted from docs/web-gs.md during the 2026-10-11 docs tidy.

Native `webgs live --mode spotter` on a Comfast CF-924AC V3 (sold as
"RTL8812BU"; chip-id 0x13 says 8822C), drone on ch 144 HT40: 79 s locked,
60 AU/s, pre-FEC and residual loss 0, RSSI −46…−50 dBm, SNR 35–37 dB, USB
p99 ~1.7 ms. Bring-up ~20 s over native libusb (efuse read 6.7 s, BB/AGC/RF
tables 9.8 s, firmware 2.2 s) against ~5 s for the 8812EU/AU. Adding the
8822C driver grew `webgs.wasm` from 2.46 to 3.09 MB.

Untested at the time of writing: the CU in Chrome, and in GS mode.
